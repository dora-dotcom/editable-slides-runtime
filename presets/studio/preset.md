# Studio

**Vibe:** High-voltage design-studio aesthetic — black canvas with electric-yellow type

**Layout:** Black bg with massive Barlow 900 yellow display headline. Occasional flipped yellow-bg slide with black ink. Mono labels in brackets.

**Typography:**
- Display: `Barlow` (900)
- Body: `Barlow` (400/700)
- Mono / accent: `IBM Plex Mono (labels)`

**Colors:**
```css
:root {
  --st-bg: #1c1c1c;
  --st-yellow: #f5d200;
  --st-yellow-soft: #f0cc00;
}
```

**Signature Elements:**
- Black canvas with electric-yellow #f5d200 as both text and accent
- Massive Barlow 900 uppercase display headlines
- Mono labels in [brackets] for studio-credit feel
- Optional flip slide: yellow ground + black ink

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/studio/template.html) (MIT). Ported 2 of N slides (cover, statement-flip).
