# Vintage Editorial

**Vibe:** Witty, confident, editorial, personality-driven

**Layout:** Centered content on cream. Abstract geometric shapes as accent.

**Typography:**
- Display: `Fraunces` (700/900)
- Body: `Work Sans` (400/500)

**Colors:**
```css
:root {
  --bg-cream: #f5f3ee;
  --text-primary: #1a1a1a;
  --text-secondary: #555555;
  --accent-warm: #e8d4c0;
}
```

**Signature Elements:**
- Abstract geometric shapes (circle outline + line + dot)
- Bold bordered CTA boxes
- Witty, conversational copy style — no illustrations, only geometric CSS shapes

**Source:** Migrated from the `frontend-slides-editable` skill (built-in preset, original to this repo). Runtime upgraded to the current standard during migration (includes the `print-color-adjust:exact` fix for PDF export).
