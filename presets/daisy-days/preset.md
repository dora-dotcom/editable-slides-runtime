# Daisy Days

**Vibe:** Pastel deck with hand-drawn daisies, rounded cards, and chunky black borders

**Layout:** Cream paper canvas with multi-color (turquoise, butter, mint, pink) rounded cards. Each card has 3px black border + 6px offset shadow. Fredoka One headlines, Quicksand body. Daisy clip-art accents.

**Typography:**
- Display: `Fredoka One` (400)
- Body: `Quicksand` (500/600)

**Colors:**
```css
:root {
  --dd-cream: #F5F0E6;
  --dd-turquoise: #7ECDC0;
  --dd-pink: #F7C8D4;
  --dd-butter: #FDE68A;
  --dd-mint: #A8E6CF;
  --dd-coral: #F8635F;
}
```

**Signature Elements:**
- Rounded pastel cards (20-28px radius) with 3px black borders
- Offset shadows (6px black, no blur) on every chunk
- Multi-color cards (turquoise / butter / mint) per slide
- Fredoka One round display + Quicksand body
- Daisy clip-path / radial-gradient as decorative accent

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/daisy-days/template.html) (MIT). Ported 3 slides (cover, three-cards, lovely afternoon).
