# Biennale Yellow

**Vibe:** Dutch-editorial poster energy — solar yellow on warm parchment with deep-indigo serif

**Layout:** Warm parchment ground with solar-yellow #F1EE2E used as both block fills and full-slide flips. Italic Instrument Serif display in deep navy ink, with warm ember accents.

**Typography:**
- Display: `Instrument Serif` (400 italic)
- Body: `Archivo` (400/500)
- Mono / accent: `JetBrains Mono (labels)`

**Colors:**
```css
:root {
  --by-paper: #E9E5DB;
  --by-sun: #F1EE2E;     /* signature solar yellow */
  --by-ink: #1B2566;     /* deep indigo navy       */
  --by-ember: #E26B4A;   /* warm peach accent      */
}
```

**Signature Elements:**
- Solar-yellow #F1EE2E full-slide flips for hero/cover
- Italic Instrument Serif display in deep-indigo navy
- Ember peach #E26B4A for emphasis swaps
- Yellow label-block (mono) callouts
- Warm parchment #E9E5DB as base ground

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/biennale-yellow/template.html) (MIT). Ported 2 of N slides (sun-cover, manifesto).
