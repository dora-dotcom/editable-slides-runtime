# Long Table

**Vibe:** Warm cream + rust-red supper-club aesthetic with uppercase grotesk headlines

**Layout:** Buttery cream paper canvas with rust-red #B53D2A as the only ink. Bold uppercase Bricolage Grotesque for headlines, italic Fraunces serif for body text. Menu-style course tables.

**Typography:**
- Display: `Bricolage Grotesque` (700/800)
- Body: `Fraunces` (400 italic)

**Colors:**
```css
:root {
  --lt-paper: #FAF1E2;     /* warm buttery cream */
  --lt-paper-d: #F2E5CF;
  --lt-paper-vd: #E8D7B6;
  --lt-ink: #B53D2A;       /* warm rust red */
  --lt-ink-dp: #8E2D1F;
}
```

**Signature Elements:**
- Single rust-red ink color across the entire deck
- Uppercase bold Bricolage Grotesque headlines
- Italic Fraunces serif body text
- Menu-style two-column course tables
- Three warm-cream grounds rotating per section

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/long-table/template.html) (MIT). Ported 3 slides (supper cover, menu, good night).
