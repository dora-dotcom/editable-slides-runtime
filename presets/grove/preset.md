# Grove

**Vibe:** Forest-green canvas with cream type and rust accent — quiet patience, long-tended

**Layout:** Deep forest-green ground with italic Playfair Display in warm cream. Occasional cream slides flip the contrast with rust meta. Jost low-weight body text. JetBrains Mono uppercase labels.

**Typography:**
- Display: `Playfair Display` (400 italic)
- Body: `Jost` (300/400)
- Mono / accent: `JetBrains Mono (labels)`

**Colors:**
```css
:root {
  --gv-bg: #192b1b;
  --gv-cream: #e8e4d6;
  --gv-text: #d4cfbf;
  --gv-rust: #b9542e;
}
```

**Signature Elements:**
- Deep forest-green canvas with italic Playfair Display in cream
- Single rust #b9542e accent for chapter markers
- Roman-numeral chapter labels (i., ii., iii.)
- Cream slide flips for chapter pauses
- Generous 80px padding for breathing space

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/grove/template.html) (MIT). Ported 3 slides (cover, chapter trio, sign-off).
