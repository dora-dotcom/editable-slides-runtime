# Pink Script

**Vibe:** Late-night editorial luxury — black canvas, hot-pink accent, pearl-cream paper

**Layout:** Deep black ground with hot-pink #ED3D8C italic display headlines, pearl-cream body text. JetBrains Mono labels for editorial credits. Thin pink rules.

**Typography:**
- Display: `DM Serif Display` (400 italic)
- Body: `Inter` (300/400)
- Mono / accent: `JetBrains Mono (labels)`

**Colors:**
```css
:root {
  --ps-ink: #060507;
  --ps-paper: #F5EDF1;
  --ps-pink: #ED3D8C;
  --ps-pink-deep: #B81D67;
}
```

**Signature Elements:**
- Hot pink #ED3D8C italic DM Serif Display headlines
- Black canvas with pearl-cream body text
- Short hot-pink rules separating chapter markers
- JetBrains Mono uppercase labels for editorial credits
- Two-voice display: italic serif + roman sans inside same headline
