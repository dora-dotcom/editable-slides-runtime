# Pastel Geometry

**Vibe:** Friendly, organized, modern, approachable

**Layout:** White card on pastel background. Vertical pills on right edge.

**Typography:**
- Display: `Plus Jakarta Sans` (700/800)
- Body: `Plus Jakarta Sans` (400/500)

**Colors:**
```css
:root {
  --bg-primary: #c8d9e6;
  --card-bg: #faf9f7;
  --pill-pink: #f0b4d4;
  --pill-mint: #a8d4c4;
  --pill-sage: #5a7c6a;
  --pill-lavender: #9b8dc4;
  --pill-violet: #7c6aad;
}
```

**Signature Elements:**
- Rounded card with soft shadow
- Vertical pills on right edge with varying heights (short → medium → tall → medium → short)
- Download/action icon in corner

**Source:** Migrated from the `frontend-slides-editable` skill (built-in preset, original to this repo). Runtime upgraded to the current standard during migration (includes the `print-color-adjust:exact` fix for PDF export).
