# Editorial Tri-Tone

**Vibe:** Dusty pink, mustard cream, and deep burgundy — saturated three-tone editorial

**Layout:** Three saturated background colors rotate slide-to-slide (pink/cream/burgundy) while italic Instrument Serif type stays constant in deep burgundy. JetBrains Mono chapter labels.

**Typography:**
- Display: `Instrument Serif` (400 italic)
- Body: `Bricolage Grotesque` (400/500)
- Mono / accent: `JetBrains Mono (labels)`

**Colors:**
```css
:root {
  --et-pink: #F2B6C6;
  --et-cream: #F2D86A;     /* mustard cream */
  --et-burgundy: #7A1F35;  /* deep burgundy */
  --et-paper: #FEFAF0;
}
```

**Signature Elements:**
- Three saturated grounds rotating per chapter
- Italic Instrument Serif headlines constant across slides
- Burgundy ink on pink/cream, cream/pink on burgundy
- Mono CHAPTER NN labels
- No accent shapes — color is the whole graphic

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/editorial-tri-tone/template.html) (MIT). Ported 3 slides (pink cover, cream method, burgundy end).
