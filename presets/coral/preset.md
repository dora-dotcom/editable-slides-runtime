# Coral

**Vibe:** Cream and coral on near-black — oversized Bebas Neue editorial

**Layout:** Massive Bebas Neue display in coral red with cream-colored ink. Alternates between near-black ground and cream ground with the same coral accent. Inter for meta labels.

**Typography:**
- Display: `Bebas Neue` (400)
- Body: `Inter` (400/700)

**Colors:**
```css
:root {
  --co-coral: #E85D5D;
  --co-cream: #F5F0E8;
  --co-black: #1A1A1A;
  --co-gray: #6B6B6B;
}
```

**Signature Elements:**
- Oversized Bebas Neue display (up to 14vw)
- Coral #E85D5D as the single chromatic accent
- Alternating black-and-cream grounds with coral consistent
- <em>-style emphasis switches color between cream and coral
- Tight uppercase letter-spacing
