# Stencil & Tablet

**Vibe:** Archaeology meets brand — bone paper with stencil-cut headlines and six-color earth palette

**Layout:** Warm bone paper canvas with Stardos Stencil headlines (stencil-cut letters). Six-color earth palette (sienna / magenta / orange / teal / red / paper) for layer tags. Barlow Condensed for orange-pill metadata.

**Typography:**
- Display: `Stardos Stencil` (700)
- Body: `Inter` (400/500)
- Mono / accent: `Barlow Condensed (tags)`

**Colors:**
```css
:root {
  --st-bone: #E2DCC9;
  --st-paper: #F4EFE0;
  --st-sienna: #A06A3C;
  --st-magenta: #C73B7A;
  --st-orange: #EE7A2E;
  --st-teal: #2D7E73;
}
```

**Signature Elements:**
- Stardos Stencil stencil-cut headline letters
- Six-color earth palette tags (sienna/magenta/orange/teal)
- Bone paper canvas with optional darker bone flip
- Orange pill labels in Barlow Condensed
- Thick 3px rules under titles

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/stencil-tablet/template.html) (MIT). Ported 3 slides (dig-site cover, four layers, sign-off).
