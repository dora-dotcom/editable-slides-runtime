# Neo-Grid Bold

**Vibe:** Editorial neo-brutalism with a single neon-yellow accent on warm off-white paper

**Layout:** Strict editorial grid with one signature accent — neon-yellow #E6FF3D — used as italic mark on key word in headlines and as fill for hero stat tiles.

**Typography:**
- Display: `Space Grotesk` (700)
- Body: `Space Grotesk` (400/500)

**Colors:**
```css
:root {
  --ng-bg: #ECECE8;
  --ng-ink: #0A0A0A;
  --ng-paper: #F5F4EF;
  --ng-accent: #E6FF3D;  /* signature neon yellow */
  --ng-muted: #8A8A85;
}
```

**Signature Elements:**
- Single neon-yellow #E6FF3D accent across the whole deck
- <mark>-style italic highlight on the key headline word
- Block-mark constellation (4 black squares) as orientation symbol
- Stat tiles with one accent-filled cell
- Off-white paper canvas — no pure white

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/neo-grid-bold/template.html) (MIT). Ported 2 of 12 slides (cover, stats).
