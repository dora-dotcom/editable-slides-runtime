# Swiss Modern

**Vibe:** Clean, precise, Bauhaus-inspired

**Layout:** Pure white canvas with strict grid, asymmetric layouts, red accent column.

**Typography:**
- Display: `Archivo` (800)
- Body: `Nunito` (400)

**Colors:**
```css
:root {
  --sw-bg: #ffffff;
  --sw-black: #0a0a0a;
  --sw-red: #ff3300;
}
```

**Signature Elements:**
- Visible grid lines on slides
- Asymmetric typographic layouts
- Left red vertical bar (~7vw)
- Top black strip with uppercase labels
- Geometric numeric/section markers

**Source:** Migrated from the `frontend-slides-editable` skill (built-in preset, original to this repo). Runtime upgraded to the current standard during migration (includes the `print-color-adjust:exact` fix for PDF export).
