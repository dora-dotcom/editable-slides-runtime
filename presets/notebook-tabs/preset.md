# Notebook Tabs

**Vibe:** Editorial, organized, elegant, tactile

**Layout:** Cream paper card on dark background. Colorful tabs on right edge.

**Typography:**
- Display: `Bodoni Moda` (400/700)
- Body: `DM Sans` (400/500)

**Colors:**
```css
:root {
  --bg-outer: #2d2d2d;
  --bg-page: #f8f6f1;
  --text-primary: #1a1a1a;
  --tab-mint: #98d4bb;
  --tab-lavender: #c7b8ea;
  --tab-pink: #f4b8c5;
  --tab-sky: #a8d8ea;
  --tab-cream: #ffe6a7;
}
```

**Signature Elements:**
- Paper container with subtle shadow
- Colorful section tabs on right edge (vertical text)
- Binder hole decorations on left
- Tab text uses viewport-scaled font-size

**Source:** Migrated from the `frontend-slides-editable` skill (built-in preset, original to this repo). Runtime upgraded to the current standard during migration (includes the `print-color-adjust:exact` fix for PDF export).
