# Capsule

**Vibe:** Modular pill-shaped cards on warm bone with a full pastel-pop palette

**Layout:** Bone canvas with pill-shape (999px-radius) cards in coral, lime, lavender, sky, yellow. Italic Bodoni Moda display headlines. Space Grotesk meta labels.

**Typography:**
- Display: `Bodoni Moda` (500 italic)
- Body: `Space Grotesk` (400/600)

**Colors:**
```css
:root {
  --cp-bg: #F5F5F0;
  --cp-coral: #E85D4E;
  --cp-lime: #C4D94E;
  --cp-lavender: #C5B5E0;
  --cp-sky: #8BB4F7;
  --cp-yellow: #F2D160;
}
```

**Signature Elements:**
- Pill-shape (999px radius) cards in pastel-pop palette
- Italic Bodoni Moda display + roman Space Grotesk body
- Six rotating chromas: coral / lime / lavender / sky / violet / yellow
- Modular grid — cards interchangeable across slides
- Soft black shadow on cards for slight depth

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/capsule/template.html) (MIT). Ported 3 slides (cover, four-pill grid, snap-done).
