# Paper & Ink

**Vibe:** Editorial, literary, thoughtful

**Layout:** Warm cream canvas with serif type, drop caps, and elegant horizontal rules.

**Typography:**
- Display: `Cormorant Garamond` (500/700)
- Body: `Source Serif 4` (400)

**Colors:**
```css
:root {
  --bg-cream: #faf9f7;
  --text-charcoal: #1a1a1a;
  --accent-crimson: #c41e3a;
}
```

**Signature Elements:**
- Drop caps on opening paragraphs
- Pull quotes set off with rules
- Elegant horizontal rules between sections
- Crimson accent on small caps headers

**Source:** Migrated from the `frontend-slides-editable` skill (built-in preset, original to this repo). Runtime upgraded to the current standard during migration (includes the `print-color-adjust:exact` fix for PDF export).
