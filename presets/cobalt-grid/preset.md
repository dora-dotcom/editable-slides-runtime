# Cobalt Grid

**Vibe:** Electric cobalt italic serifs on a graph-paper canvas with pixel-glitch decorations

**Layout:** Ivory paper canvas overlaid with a 32px cobalt graph grid. Italic Newsreader display in electric cobalt. Pixel-block decorations populate the margins like manuscript errata. DM Mono labels.

**Typography:**
- Display: `Newsreader` (400/500 italic)
- Body: `Hanken Grotesk` (400/500)
- Mono / accent: `DM Mono (labels)`

**Colors:**
```css
:root {
  --cg-paper: #F0EBDE;
  --cg-ink: #1F2BE0;     /* electric cobalt */
  --cg-ink-soft: #5560E5;
  --cg-grid: rgba(31, 43, 224, 0.10);
}
```

**Signature Elements:**
- 32px cobalt graph grid overlay on every slide
- Italic Newsreader display, never roman — the slant is the brand
- Cobalt 12×12 pixel blocks as glitch / errata accents
- DM Mono labels in code-comment syntax (//, /*)
- Ivory paper #F0EBDE warm ground

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/cobalt-grid/template.html) (MIT). Ported 3 slides (cover, method, end).
