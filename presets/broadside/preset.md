# Broadside

**Vibe:** Near-black canvas with hot-orange print accents — broadsheet front-page energy

**Layout:** Near-black ground with massive Barlow 900 uppercase headlines. Hot orange #e85d26 as accent for em emphasis, rules, and full-bleed alternate slides. IBM Plex Mono section labels in brackets.

**Typography:**
- Display: `Barlow` (900)
- Body: `Barlow` (400/500)
- Mono / accent: `IBM Plex Mono (labels)`

**Colors:**
```css
:root {
  --br-bg: #111111;
  --br-bg-alt: #1a1a18;
  --br-orange: #e85d26;     /* hot orange */
  --br-fg: #f0ece5;
  --br-fg-2: #888880;
}
```

**Signature Elements:**
- Near-black canvas with hot-orange accent only
- Massive Barlow 900 uppercase headlines
- <em>-style emphasis switches color to hot orange
- Full-bleed orange flip slide for headline punch
- IBM Plex Mono in [brackets] for section markers

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/broadside/template.html) (MIT). Ported 3 slides (cover, orange-flip headline, end of issue).
