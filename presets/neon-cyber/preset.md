# Neon Cyber

**Vibe:** Futuristic, techy, confident

**Layout:** Deep navy canvas with cyan/magenta neon accents and grid patterns.

**Typography:**
- Display: `Clash Display` (600)
- Body: `Satoshi` (400/700)

**Colors:**
```css
:root {
  --bg-deep: #0a0f1c;
  --accent-cyan: #00ffcc;
  --accent-magenta: #ff00aa;
  --text-light: #e0fff7;
}
```

**Signature Elements:**
- Particle backgrounds
- Neon glow on key text
- Grid patterns underlay
- Cyan + magenta dual accents

**Source:** Migrated from the `frontend-slides-editable` skill (built-in preset, original to this repo). Runtime upgraded to the current standard during migration (includes the `print-color-adjust:exact` fix for PDF export).
