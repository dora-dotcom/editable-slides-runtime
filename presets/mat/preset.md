# Mat

**Vibe:** Dark sage canvas with bone paper and burnt-orange — mid-century modern with wood undertones

**Layout:** Deep forest-green ground alternating with bone-cream slides. Bricolage Grotesque headlines in cream-on-green or ink-on-cream. Burnt-orange micro accents and rules. DM Mono labels.

**Typography:**
- Display: `Bricolage Grotesque` (600/700)
- Body: `DM Sans` (300/400)
- Mono / accent: `DM Mono (labels)`

**Colors:**
```css
:root {
  --mt-bg: #232e26;        /* dark sage */
  --mt-cream: #ede6d0;     /* bone paper */
  --mt-text: #f0e8d2;
  --mt-orange: #d97b3e;    /* burnt orange */
}
```

**Signature Elements:**
- Dark sage forest-green canvas as primary ground
- Bone-paper cream slides for breathing-room intermissions
- Burnt-orange #d97b3e as the single chromatic accent
- Bricolage Grotesque modern-grotesque headlines
- DM Mono in brackets for warm-numeric labels

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/mat/template.html) (MIT). Ported 3 slides (sage cover, cream method, sage sign-off).
