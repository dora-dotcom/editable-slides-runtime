# Sakura Chroma

**Vibe:** Vintage Japanese cassette-package aesthetic — diagonal rainbow ribbons + JIS checkboxes

**Layout:** Warm cream paper canvas with diagonal rainbow ribbon stripes (red/orange/pink/green/blue). Big Shoulders Display 900 uppercase headlines. Albert Sans body. Noto Sans JP Japanese accents. JIS-style square checkboxes.

**Typography:**
- Display: `Big Shoulders Display` (900)
- Body: `Albert Sans` (400/500)
- Mono / accent: `JetBrains Mono · Noto Sans JP`

**Colors:**
```css
:root {
  --sk-paper: #F1E6CB;
  --sk-ink: #3A2516;
  --sk-red: #E5392A;
  --sk-pink: #E54489;
  --sk-orange: #F09131;
  --sk-green: #3D9F47;
  --sk-blue: #3F8BC4;
}
```

**Signature Elements:**
- Diagonal rainbow ribbon stripes (-3° rotation) crossing the slide
- Big Shoulders Display 900 uppercase headlines
- Five chromatic accents (red/orange/pink/green/blue) cycling
- JIS-style square pink checkbox markers
- Japanese script intermixed (Noto Sans JP)
