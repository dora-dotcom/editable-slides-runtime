# Terminal Green

**Vibe:** Developer-focused, hacker aesthetic

**Layout:** GitHub-dark canvas with monospace-only typography and code framing.

**Typography:**
- Display: `JetBrains Mono` (500)
- Body: `JetBrains Mono` (400)

**Colors:**
```css
:root {
  --bg-deep: #0d1117;
  --accent-green: #39d353;
  --text-light: #c9d1d9;
}
```

**Signature Elements:**
- Scan lines overlay
- Blinking cursor on titles
- Code-syntax styling for headings
- Monospace everywhere — no proportional fonts

**Source:** Migrated from the `frontend-slides-editable` skill (built-in preset, original to this repo). Runtime upgraded to the current standard during migration (includes the `print-color-adjust:exact` fix for PDF export).
