# Playful

**Vibe:** Sun-warm peach background with Syne display — indie launch aesthetic

**Layout:** Sun-warm peach background with optional light-peach intermissions. Heavy Syne 800 hero in black, Space Grotesk meta. Black pills for primary tags, coral pills for accent.

**Typography:**
- Display: `Syne` (700/800)
- Body: `Space Grotesk` (400/600)

**Colors:**
```css
:root {
  --pf-bg: #F0C8A0;
  --pf-bg-alt: #E8B88E;
  --pf-light: #F7DEC6;
  --pf-text: #1A1A1A;
  --pf-coral: #F86F5F;
}
```

**Signature Elements:**
- Sun-warm peach #F0C8A0 canvas with lighter peach flips
- Heavy Syne 800 in black for hero type
- Black pill labels with optional coral pills for accent steps
- Generous 64px padding throughout
- Wide hero / narrow body copy ratio

**Source:** Ported from [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates/blob/main/templates/playful/template.html) (MIT). Ported 3 slides (peach cover, light-flip features, hi-live).
