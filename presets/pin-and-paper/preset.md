# Pin & Paper

**Vibe:** Yellow paper field-guide with safety-pin marks and ink-blue Caveat handwriting

**Layout:** Lemon-yellow paper canvas with subtle multi-stop noise grain. Space Grotesk uppercase headlines in deep ink-blue. Caveat handwriting for marginal notes. Safety-pin glyph as anchor mark.

**Typography:**
- Display: `Space Grotesk` (600/700)
- Body: `Space Grotesk` (400)
- Mono / accent: `Caveat (handwriting) · DM Mono (labels)`

**Colors:**
```css
:root {
  --pn-paper: #F5ECA0;     /* yellow paper */
  --pn-ink: #1F3A8A;       /* ink blue */
  --pn-ink-deep: #0F1F4A;
}
```

**Signature Elements:**
- Lemon-yellow paper ground with subtle multiply-blend noise grain
- Deep ink-blue Space Grotesk uppercase headlines
- Caveat handwriting for asides and annotations
- Safety-pin clip-path mark as decorative anchor
- DM Mono section labels with /, →, — prefixes
